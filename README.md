# DiceStats

CCFolia のログからダイスロール統計を生成・表示する Web アプリケーションです。

## 機能

- CCFolia のログファイルをアップロードして統計を表示
- プレイヤー別のクリティカル/ファンブル発生回数を集計
- 結果の表形式での表示

## 開発環境のセットアップ

### 必要な環境

- Node.js 18.0.0 以上
- npm 9.0.0 以上

### インストール

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

### 開発用コマンド

```bash
# 開発サーバーの起動
npm run dev

# ビルド
npm run build
```
